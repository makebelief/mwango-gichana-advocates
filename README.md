# Mwango Gichana & Co. Advocates — demo website

Premium static multi-page demonstration site built from verified public information and client-supplied brand assets.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run check
```

## Important production note

The public sources reviewed did not provide a verified firm phone / WhatsApp number or a verified street office address. The floating contact rail therefore scrolls to the contact section instead of inventing a number. Replace `FIRM_PHONE` in `assets/js/site.js` once the number is confirmed; the WhatsApp and `tel:` links will activate automatically.
